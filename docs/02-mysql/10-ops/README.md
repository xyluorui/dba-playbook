# 10 · 运维与管理

围绕 MySQL 实例的日常运维：部署、备份、监控、变更、安全、升级。

## 本章范围

| 主题 | 内容 |
|------|------|
| 部署与配置 | 安装、参数基线、版本选择 |
| 备份与恢复 | 逻辑备份（mysqldump / mydumper）、物理备份（XtraBackup）、增量备份、PITR、恢复演练 |
| 监控与告警 | 核心指标、告警阈值、巡检清单 |
| 变更与规范 | DDL 规范、命名规范、在线 DDL（gh-ost / pt-osc） |
| 安全与权限 | 权限模型、角色、审计、加密、脱敏 |
| 升级与迁移 | 5.7 → 8.0、数据迁移方案对比 |
| 容量与故障 | 容量规划、连接打满、磁盘满、长事务、OOM |
